# paris-data-dept

A simulated **data department** running on **live Paris data**: Vélib' bike stations, weather and French fuel prices.
Built level by level, from plain data plumbing to AI agents that propose operations a human approves.

| Level | Team | Status |
|---|---|---|
| 1 | Data Engineering: live ingestion → lake → warehouse, orchestrated by n8n | 🚧 in progress ([guide](LEVEL1.md)) |
| 2 | Data Quality: agents detect and propose fixes, human approval | ⏳ |
| 3 | Analytics: question-answering crew on the warehouse | ⏳ |
| 4 | BI: dashboard + weekly Excel report | ⏳ |
| 5 | Chaos monkey + evals | ⏳ |
